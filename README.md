# KFI'S

Gestion financière familiale de Khalil et Yousra (Montréal, CAD).

**Application :** https://dizey7.github.io/kfis/

- Les données sont enregistrées **uniquement sur l'appareil** (navigateur). Aucun montant n'est envoyé sur Internet ni stocké dans ce dépôt.
- Sauvegarde / restauration par fichier dans Paramètres.
- Montants en cents entiers, périodes de paie de 14 jours, saisie en langage naturel.
